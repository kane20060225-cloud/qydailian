# B18 深浅主题同步

深色继续使用 B17 的原有配色：背景 `#0a0f1a`、卡片 `#141b26`、橙色强调 `#f0a050`、正文 `#e2e8f0`，保留背景图、橙色渐变按钮、蓝色登录按钮以及三方订单各阶段颜色。浅色保留 B17 的白灰底色和蓝色强调。

将原先仅作用于浅色的布局、字号、间距、选项控件、订单卡片、后台导航、弹窗和移动端规则统一到 `public/theme-components.css`。`light-theme.css` 只覆盖颜色及背景变量，不再定义独立布局。两种主题共用组件和断点，原有深色 `style.css` 内容保持不变。

浏览器验收覆盖 1440、768、650、390、360 像素宽度。对首页、下单、租号大厅、个人订单、三方订单、后台、订单详情及主题设置逐项比较可见元素位置、尺寸、字体、间距、圆角；两种主题布局一致，无横向溢出和脚本错误。检查深色原配色不变、浅色文字对比度、主题预览、账号保存失败反馈及重试。下单流程回归通过桌面和手机检查，含安全草稿、登录恢复、提交摘要、租赁筛选与租期价格、订单指引及后台优先级。

本批只发布四个前端运行文件：`index.html`、`ui-foundation.css`、`light-theme.css`、新增 `theme-components.css`。无需数据库迁移或后端重启。
