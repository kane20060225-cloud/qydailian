# B20 管理入口与登录设备

订单管理保留“经营指标”入口，默认不展开、不请求统计；打开独立弹窗后查看近90天数据，可刷新指标，关闭后保留订单筛选与位置。

打手工作状态、上下线操作和排班集中在“打手工作台 → 上下线设置”。接单大厅、我的订单和收益不再显示状态卡片。未保存排班离开标签时提供提示。

“设置 → 登录设备”按浏览器保存的随机设备标识合并后续登录，显示最近10台设备、最近登录时间（北京时间）、IP 和推测地点。浏览器升级、IP 改变沿用同一设备记录；不同浏览器或清空浏览器存储会产生新的标识。历史记录没有设备标识，按浏览器信息合并展示，不删除原始历史记录，无法精确区分历史上浏览器信息完全相同的不同实体设备。

新增 nullable `login_devices.device_key` 与唯一索引 `(user_id,device_key)`，登录成功后更新最新时间、浏览器信息和 IP。仅在查询登录设备时请求位置，不阻塞登录。地点使用 [ipwho.is 官方接口](https://ipwhois.io/documentation) 的中文国家、省市信息；私有地址不发送到外部，查询超时或失败显示暂不可用。同一IP缓存一天，失败缓存一分钟，进程设置每日900次保护上限。地点为IP推测，不代表精确位置。API只允许当前登录用户查询自己的设备，禁用缓存，不返回内部设备标识。

部署前备份站点及数据库，依次运行 B19 与 B20 的 `--plan` / `--apply` 迁移，随后发布文件并重启 `my-backend`。B20 迁移可重复执行，仅增加列和索引，不清理历史记录。回滚运行文件可保留两批新增结构与管理员配置。部署结果另见发布记录。

验证包括设备身份隔离、最新登录更新、旧记录合并、私有 IPv4/IPv6、位置缓存及失败、查询用户隔离，以及两主题桌面/手机的设置页、HTML转义、失败重试和指标按需加载。全部使用本地合成数据；生产仅执行读取与健康检查。
