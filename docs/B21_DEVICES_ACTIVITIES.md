# B21 登录设备与下单活动入口

下单页在“代练下单”标题后展示礼物活动按钮，有活动时使用金橙色边框和数量提示。点击打开居中原生对话框，支持关闭按钮、Escape、点击遮罩关闭；选择关联服务后关闭窗口并回到下单流程。空活动和加载失败分别显示提示，失败可在弹窗重试。移除电脑端活动侧栏和主区域左对齐规则，恢复下单区域居中与对称留白，保留服务选择和结算的左右排列。

活动弹窗内部使用单列卡片，单条活动铺满内容区域，多条活动垂直排列，长内容在窗口内滚动且关闭按钮保持可见。首页活动区继续使用原有响应式布局。

登录设备按固定浏览器标识保留不同设备。历史无标识记录与按浏览器信息生成的旧回退标识可匹配到唯一的固定标识；归并后取最新登录的整条记录，包括时间、IP 和推测地点。iOS 历史 Safari 信息中可选 Version/Safari 字段缺失不再造成额外卡片。若同一浏览器信息对应多个明确设备标识，保留各设备和无法判定归属的历史项，避免错误归并。历史原始记录不删除。

浏览器随机标识增加同站点非认证 Cookie 备份，单独丢失 localStorage 时可恢复；Cookie 不包含账号或登录令牌。不同浏览器、隐私模式或同时清空 Cookie 与本地存储仍可能产生独立标识，网页无法可靠识别它们是否来自同一台实体设备。

发布包含 public/index.html、public/script.js、public/service-content.js、public/service-content.css 和 backend/lib/login-devices.js，并重启后端。已有 B20 设备列和唯一索引的环境无需新增数据库迁移。发布工具核对线上文件基线、设备表结构及唯一索引，创建受保护备份，替换后校验公网文件哈希、健康接口和访问权限；验证失败时恢复本批文件并重启旧版本。发布结果另见部署记录。

验证：238 项后端测试通过；深浅主题下 1920、1440、768、390 宽度的活动入口、空态、失败重试、对称留白、弹窗关闭、活动关联下单及草稿恢复通过。深浅主题下 1440、390 宽度的设备标识恢复、设置展示、北京时间、HTML 转义和失败重试通过。全部使用本地合成数据。
