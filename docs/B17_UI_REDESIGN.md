# B17 界面与浅色主题重构

本批在本地完成，尚未部署生产或同步云仓库。基于已发布 B16，不需要数据库迁移。

## 视觉体系

`public/ui-foundation.css` 管理共用字体、行高、输入框、触控尺寸、焦点、禁用与处理状态、弹窗溢出及减少动画偏好。`public/light-theme.css` 独立管理浅色布局与组件，旧 `style.css` 和在线状态样式中的浅色覆盖已移除。

浅色主题使用柔和灰底、纯白内容区、深色正文与蓝色操作入口。去除背景图、发光效果、表单选中浮动；统一内容层次、边框、圆角、间距、价格与状态色。首页服务区、下单步骤、租号筛选、订单卡片、下一步指引、后台经营指标、三方工作台、通知、工具和设置均纳入同一体系。

手机端重新调整标题、服务卡片、流程、表单与详情弹窗。固定费用栏适配底部导航；601–700px 没有底部导航时直接贴底。长用户名可截断，不挤出导航。

## 文案

统一使用：账号租赁（服务名称）、租号大厅（查找入口）、实用工具、管理员后台、打手工作台、界面主题、深色主题、浅色主题、情谊积分、返回首页。保留具体业务状态，不将待付款、付款凭证待核实、已收款待接单混为同一状态。个人资料打手身份显示中文。

主题选择提供实际视觉预览。顶部按钮允许登录前切换，浏览器记住选择；页面加载前读取主题，减少闪烁。设置中保存成功后才提示账号已同步，失败时保留浏览器选择并允许重试。

订单处理中使用 `aria-busy` 和关闭按钮禁用状态，完成后恢复键盘焦点。操作保留原业务权限及记录规则。
