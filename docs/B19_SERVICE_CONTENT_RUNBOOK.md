# B19 深色配色恢复、网页项目编辑与活动展示

## 使用入口

管理员登录后，可从代练下单的“编辑项目”进入，也可使用“管理员后台 → 内容管理 → 代练项目”。编辑项目名称、图标、简介、A/B/C 方案内容和基础单价，新增项目或上下架；方案也可以单独停用。最多30个项目，至少保留一个上架项目。项目标识稳定，用于草稿恢复和活动关联。已有订单保存的名称、内容、单价不会被追改。

“内容管理 → 活动管理”可发布游戏活动或平台活动，填写说明、浏览器本地时间的起止时间、可选来源链接、可选关联代练方案。活动只在发布且处于有效时间内展示，结束后下架；每分钟读取最新配置。关联项目下架时保留活动说明，但不再提供下单按钮。不关联项目的活动按说明参与，不制造虚假优惠或当前官方活动。活动内容默认留空，待管理员发布真实内容。

首页有可收起活动区；下单页在1400像素及以上宽度时，将活动放到右侧空位。平板和手机放在服务选择之前，以可收起活动区展示，不使用浮层遮挡表单。没有活动时，普通用户不显示活动区，维持原有表单宽度。管理员可看到空状态指引。活动按钮选择关联项目与方案，显示计价说明，并将活动标题附加到订单备注；用户仍经过填写和确认步骤，不自动提交订单。

## 配色恢复

新增 `public/dark-theme.css`，仅恢复深色组件颜色和原有选中光效，不定义尺寸、字号、间距或布局。恢复首页代练卡片橙色渐变/边框、主行动按钮、下单下一步/提交按钮、选项背景与橙色选中强调、价格底色和金色金额、登录/注册按钮、弹窗标题、订单金额与三方待收款颜色。使用低额外权重的主题作用域，避免通用按钮规则覆盖删除和付款等状态色。两种主题继续共用 B18 的布局。

## 后端与发布

新增独立配置表 `site_service_content`，存储当前配置、整体修订版本、项目价格版本和最后编辑人。管理员写入沿用实际会话及管理员权限校验，在事务内保存并记录 `operation_audit`。并发编辑版本不匹配时返回409，不覆盖他人修改；审计失败则回滚保存。

公开读取只输出已上架项目及有效活动，禁用缓存。创建订单在事务中锁定配置，用服务器配置核对方案、数量、打手倍率、加急、金额及积分参数；旧价格、下架选项和过期项目版本在扣积分之前拒绝。仅更新活动不改变价格版本，不打断确认中的订单；项目配置变化则要求重新确认。浏览器草稿只保留原有服务选项和数量，动态新增项目也可恢复，密码、账号、UID和备注均不保存。

部署须先备份现有站点和数据库，在 `backend` 目录执行：

```powershell
node scripts/migrate-b19-service-content.js --plan
node scripts/migrate-b19-service-content.js --apply
```

迁移只创建配置表并在首次缺少配置时写入现有七个项目；`INSERT IGNORE` 保留已编辑的配置。发布本批前后端文件后需要重启后端。服务器库、运行环境和上传目录沿用现有内容，禁止将本地环境配置覆盖到服务器。回滚恢复上一批运行文件，保留新增配置表及管理员编辑数据，不回滚或修改历史订单。

## 验证

229项后端测试通过，包括实际订单路由的旧报价拒绝与零积分误扣检查、全额积分订单、29积分抵扣的精确分值计算、权限、并发版本、事务回滚、活动边界和关联项目下架。浏览器使用本地接口及合成数据，不访问生产、不创建真实订单：深浅主题各1920、1440、768、390宽度验证项目编辑、新增项目草稿、活动发布与关联选择、侧栏/手机布局、配置加载及保存失败重试、活动说明更新不打断确认、改价后重新确认及最终报价。两主题另有五种宽度、八个页面的布局比较；桌面及手机原有下单流程回归通过。

本批与 B20 管理入口及登录设备调整一起发布，实际部署与云同步结果见 B20 发布记录。
