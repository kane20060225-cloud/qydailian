## 问题与修复

- 客服悬浮按钮原本只避开底部导航，和固定下单栏占用同一位置。现在测量导航、下单栏和客服按钮的实际高度，让客服位于下单栏上方并保留12px间距；下单栏避开导航。切换页面、调整窗口和控件边框盒高度变化时更新测量，支持安全区域导致的导航高度变化。
- 手机三方订单筛选栏受 flex 最小内容宽度影响，在320–430px屏幕上宽531px，栏内没有产生可滚动溢出，右侧被卡片裁切。现在限制筛选栏为容器宽度、允许 flex 收缩，后续筛选可通过触摸横向滑动显示；搜索文字保持一行。
- 三方订单和下单页面按底部控件实际高度预留空间，最后一张订单及其操作可以完整滚动到悬浮控件上方。
- 更新相关CSS与主脚本的资源版本，刷新页面即可加载修复。
