## 结单流程

- 打手完成服务后必须上传一张 PNG 或 JPEG 结单截图（不超过 5MB），可填写说明。
- 提交后订单仍为代练中，在工作台单独显示「待审核」，不会产生收益或积分。
- 管理员在「管理后台 → 订单管理 → 结单审核」查看截图，再通过或填写原因驳回；订单中心待验收列表也能跳转到该入口。
- 通过后才在同一事务内完成订单、按订单现金结算价的 75% 入账并发放原有奖励。驳回不结算，打手可根据原因上传新截图重新提交。
- 订单行锁、待审核检查和唯一结算流水共同防止重复提交、重复审核和重复入账；失败事务会回滚，未提交成功的截图会移除。
- 截图存储在后端私有目录 `private-uploads/boost-completion`，读取接口验证管理员、对应打手或下单用户身份，不通过公开 `/uploads` 目录暴露。
