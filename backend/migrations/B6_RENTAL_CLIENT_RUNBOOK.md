# B6.4 租号前端客户端与短缓存

此批只改前端：租号账号的大厅、详情、出租方状态和管理员审核请求统一经过
`rental-client.js`；公开租号大厅的请求缓存 5 秒、并发去重，管理员审核及出租方
下架会使同浏览器缓存失效。管理员列表及个人列表不缓存，避免隐藏审核状态。

MySQL JSON 截图字段可能是数组或 JSON 字符串；新模块统一解析并限制为站内
安全文件名。MySQL DECIMAL 租价在浏览器中可能是字符串，详情价格计算先转
为数字。租号大厅和详情中的用户文本继续 HTML 转义，不改支付、租单结算或
数据库结构。

发布前核对线上运行文件与 B6.2 基线一致，制作新的受限应用备份，在隔离
发布目录跑全量合成凭据测试与 JS 语法检查。仅按 `rental-client.js` →
`index.html` → `script.js` 顺序部署本批前端白名单文件，不覆盖 `.env`、
上传目录、支付宝配置或后端。验收包括静态文件 200、健康接口、匿名租号列表
200、管理员匿名接口 401；用户重新载入页面后测试管理员审核与租号详情。

若新脚本未正确加载，恢复本批前端三文件的备份版本。浏览器如果保留旧页面
缓存，须强制刷新后再判断，不对生产订单或账号状态作自动修正。
