# B6.6 租号账号后端路由模块

租号账号公开列表、详情、发布、出租方状态、删除/恢复、管理员审核与账号截图
上传，从单体 `server.js` 迁移到 `routes/rental-accounts.js`。数据库池、鉴权、
管理员鉴权、操作审计、上传服务及上传目录全部由入口显式注入；租号订单付款、
退款、争议与结算路由仍留在原入口，避免一次性大重构。

此批不改变 URL、HTTP 方法、返回结构、数据库结构或支付逻辑。原路由代码已从
入口删除，不保留重复注册或死代码。原有 HTTP 测试继续从完整 Express 应用
验证权限、事务回滚、分页、软删除和订单保护，另加模块边界测试。

部署须与 B6.3 加法迁移一起遵守顺序：先备份并应用/验证软删除字段和索引，
再部署包含入口与新路由模块的代码；不得先部署会读取 `deleted_at` 的代码。
隔离环境须运行全量测试和 JS 语法检查，生产部署不得覆盖 `.env`、密钥、上传
目录或依赖。若运行异常，使用同批应用备份整体恢复入口和路由文件，不能只
恢复其中一个文件。
